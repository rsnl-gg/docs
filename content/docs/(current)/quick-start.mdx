This is the Mod Management tutorial Arsenal plays after onboarding. You can run it again from **Settings > Mod Management > Replay Tutorial**.

Install [Arsenal](https://rsnl.gg/downloads), finish the onboarding wizard, then follow these steps in order. The in-app tour starts on the **Library**, then switches to the **Default** profile.

<Steps>
<Step>

### Your Mod Library

Click **Library** in the sidebar. That is where every imported mod is stored. From the Library you can import new mods and manage your collection.

The Library does not deploy anything. Deployment always happens from a profile.

</Step>
<Step>

### Import Mods

Click **Add Mod** to import into Arsenal. You can select mod archives (`.zip`, `.rar`, `.7z`) or folders that contain mod files. You can also drag and drop archives directly onto this window.

</Step>
<Step>

### Download from Nexus Mods

You can also download mods directly from Nexus Mods. Click the download icon in the title bar to open the Downloads panel, then use **Mod Manager Download** on the Nexus Mods website to send files into Arsenal automatically.

Sign in from the title bar account menu first. Details are on [Adding Mods](/mod-management/adding-mods).

</Step>
<Step>

### Your Profiles

After the Library steps, Arsenal opens the **Default** profile. Profile icons sit in the sidebar under Library. Each profile has its own set of mods. Click a profile to switch to it, or drag icons to reorder them.

</Step>
<Step>

### Create a New Profile

Click **+** at the bottom of the sidebar profile list to create a new profile. Use multiple profiles to switch quickly between different mod setups for different playstyles.

</Step>
<Step>

### Manage Your Profiles

Right-click any profile in the sidebar, or click the **gear** on the profile badge in the table header, to rename, duplicate, change the image, or delete a profile. The Default profile cannot be renamed or deleted.

</Step>
<Step>

### Organize with Separators

Use separators to group mods into categories. Click **Add Separator**, then drag it into place in the mod list.

</Step>
<Step>

### Add Mods to Profile

Click **Add Mod** on a profile to import new archives into that profile, or to select existing mods from your Library. Only mods added to a profile can be deployed to the game.

</Step>
<Step>

### Mod Deployment Status

The colored circle around each mod icon shows its deployment status:

| Color | Meaning |
|-------|---------|
| **<span style={{ color: "#e24327" }}>Red</span>** | Not deployed |
| **<span style={{ color: "#fea500" }}>Yellow / orange</span>** | Changed since last deploy (needs redeployment) |
| **<span style={{ color: "#00c853" }}>Green</span>** | Deployed correctly |

</Step>
<Step>

### Enable Your Mods

Use the row switch to enable or disable a mod. Only enabled mods will be deployed to Helldivers 2.

</Step>
<Step>

### Deploy Mods

Click **Deploy** to install all enabled mods into your Helldivers 2 game folder. Your mods will be active the next time you launch the game.

</Step>
<Step>

### Launch the Game

After deploying, click the Helldivers skull button to launch Helldivers 2. You can also launch safely from Steam.

</Step>
</Steps>

For filters, options, conflicts, and load order, continue with [Mod Management](/mod-management).
