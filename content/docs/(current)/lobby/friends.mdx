The left column of Lobby is your **social** panel. It uses the same Discord account as the listing. `Ctrl + K` focuses **Search friends...**.

## User card

Your avatar, clan tag, display name, and role sit at the top.

| Control | Action |
|---------|--------|
| Discord ID | Hidden until you click **Show Discord ID**. Copy with the copy button |
| Gear | Opens **User Profile** (self): edit display name, logout |

Display name is what others see in lobbies (maximum 64 characters). Leave it empty to reset to your Discord name. **Logout** disconnects Discord and the lobby server.

Roles that can appear on names: Staff Member, Elite Supporter, Early Supporter, Supporter, User.

## Panel sections

| Section | Contents |
|---------|----------|
| Online | Online friends |
| Pending Requests | Incoming requests with Accept / Decline |
| Clan Invites | Invites to a clan if you are not in one |
| Clan Header | Your clan name and tag, plus online members who are not already listed as friends |
| Offline | Offline friends (collapsed by default) |
| Sent Requests | Outgoing requests with Cancel |
| Blocked | Blocked users with Unblock |

**Add** (`+`) opens **Add Friend**.

## Add a friend

**Add Friend** / **Send a friend request using their Discord ID.**

1. Paste a numeric Discord ID (17 to 20 digits)
2. Click **Send Request**

| Result | Meaning |
|--------|---------|
| You are now friends! | They already had a request to you, so both sides accepted |
| Friend request sent! | Waiting on them |
| Enter a valid Discord ID. | Format check failed |

You can also add from a **User Profile** or from a right-click menu on a player or social row.

## Context menus

Right-click a person in the social list or in a room (not yourself):

| Action | Notes |
|--------|--------|
| View Profile | User Profile overlay |
| Invite to Lobby | Only while you are in a room |
| Add Friend / Cancel Request | |
| Remove Friend | Confirmation required |
| Block User | They cannot send you friend requests |
| Unblock User | |
| Invite to Clan / Cancel Clan Invite | Clan managers. See [Clans](/lobby/clans) |

## User Profile

**User Profile** shows role, clan (or **No clan**), and actions: Add Friend, Remove Friend, Block, Unblock, Invite to Clan.

On your own profile: **Edit Display Name**, **Logout**, and a hint if the Discord avatar may be outdated.
