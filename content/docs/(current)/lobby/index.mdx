The **Lobby System** lets you browse public rooms, host your own, share a mod loadout, and drop into Helldivers 2 together. Open it from the sidebar people button (tooltip: **Find or create a lobby**).

The navbar reads **LOBBY**, then **LISTING** or **ROOM**.

<Callout title="Discord required">
  You must sign in with Discord before you can browse, create, or join lobbies. Friends, clans, and chat use the same account.
</Callout>

## What you get

The login screen summarizes the four parts of the system:

| Feature | What it does |
|---------|----------------|
| **Lobby Rooms** | Create or join rooms. Set region, difficulty, faction, and coordinate in real time |
| **Mod Sync** | The host shares a loadout. Guests download, deploy, and launch with the same mods |
| **Friends & Social** | Add friends, see who is online, invite them, and chat |
| **Clans** | Create or join a clan. The clan tag appears on names across lobbies |

## Sign in

1. Open **Lobby**
2. Optionally check **Automatically log in next time**
3. Click **Login with Discord**
4. Complete Discord authorization in the browser

While OAuth runs, the button shows **Connecting...**. After Discord succeeds, Arsenal connects to the lobby server (**Connecting to lobby system...**).

If the account is suspended, Arsenal shows **Account suspended**. Appeals go through [discord.rsnl.gg](https://discord.rsnl.gg).

## Sidebar badges

| Badge | Meaning |
|-------|---------|
| **NEW** | First time the Lobby button is shown. It clears after you open Lobby once |
| Chat count | Unread room chat while you are in a lobby but looking at another menu (caps at `99+`) |

## Friend code

Helldivers 2 uses an 8-digit friend code (`XXXX-XXXX`) so players can add each other in-game.

The **host** can set, copy, or remove that code from the room (**Host Friend Code** / **Edit Friend Code**). Guests copy the host code and enter it in Helldivers 2.
