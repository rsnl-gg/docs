A **clan** is a named group with a short **tag** that prefixes names in listings, rooms, and chat (`[TAG] Name`). You can belong to one clan at a time.

If you are not in a clan, the listing sidebar offers **Join a Clan** (browse) and **or create your own**.

## Browse Clans

**Browse Clans** / **Find and join a clan of Helldivers.**

| Control | Action |
|---------|--------|
| Search | **Search clans...** |
| Region | All Regions, Global, or a lobby region |
| Join Mode | All, Open, Request to Join, Invite Only |
| Tags | Server-defined chips |

Cards show tag, name, member count, region, join mode, and tags. **20** clans per page (**Prev** / **Next**). Empty: **No clans found**.

## Create or edit

**Create Clan** (or **Edit Clan** for managers):

| Field | Limit | Notes |
|-------|-------|--------|
| Clan Name | 64 | Required |
| Clan Tag | 4 | Required. Shown as `[TAG]` |
| Description | 2000 | Optional |
| Region | | Global or a lobby region. Required |
| Join Mode | | Open, Request to Join, or Invite Only |
| Tags | | Optional chips |
| Logo | PNG, JPEG, or WebP | Click to upload or change |

**Name, tag, and region are required.** Oversized logos show **Image must be under 5 MB**.

## Join modes

| Mode | How people join |
|------|-----------------|
| **Open** | **Join Clan** on the clan page |
| **Request to Join** | **Request to Join**. Managers Accept or Decline under **Join Requests** |
| **Invite Only** | A manager invites from a profile or social context menu. You accept from **Clan Invites** in the social panel |

## Clan page

Title **CLAN**. Depending on your role:

| Action | Who |
|--------|-----|
| Join / Request to Join | Outsiders, when the mode allows |
| Edit | Owner, Admin |
| Delete | Owner. Confirmation: this cannot be undone |
| Leave | Members and admins. The owner must **Transfer Ownership** or delete first |
| Transfer Ownership | Owner. You become an admin. Cannot undo |

Members list with roles **Owner**, **Admin**, and member. Right-click (managers): **Promote to Admin**, **Demote to Member**, **Kick from Clan**, **Transfer Ownership**.

<Callout type="warn" title="Owner leaving">
  You must transfer ownership or delete the clan before leaving. Transfer needs another member.
</Callout>
